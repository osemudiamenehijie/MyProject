# User stories

## Product management

- **US-1:** As a shop owner, I want to add a product with a unique SKU, price, quantity, and category so that I can keep my stock list organized.
- **US-2:** As a staff member, I want to search products by name or SKU so that I can find an item quickly.
- **US-3:** As a shop owner, I want to update or remove a product so that the list reflects what the shop currently sells.

## Inventory

- **US-4:** As a staff member, I want to record stock arriving so that the available quantity increases and the change is recorded.
- **US-5:** As a staff member, I want to record stock leaving for a reason other than a sale so that the available quantity stays accurate.
- **US-6:** As a shop owner, I want to see items at or below their low-stock threshold so that I can plan a reorder.
- **US-7:** As a shop owner, I want a movement history so that I can understand when and why stock changed.

## Sales and reports

- **US-8:** As a staff member, I want to record a sale so that the system reduces stock automatically.
- **US-9:** As a staff member, I want the application to reject a sale above available stock so that inventory cannot become negative.
- **US-10:** As a shop owner, I want daily and monthly sales summaries so that I can review business activity.
- **US-11:** As a shop owner, I want to export product and sales records as CSV so that I can use them in other tools.

## Persistence

- **US-12:** As a shop owner, I want records saved in a local database so that they remain available after I close the application.
